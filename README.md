# Green Quest

Welcome to **Green Quest**, my very first game development project built with Unity! It is a simple, fun quiz game where I focused on learning the basics of game development.

## Play & Download
You can download and play the full Windows version of the game from my official itch.io page:
👉 **[Download Green Quest on itch.io](https://umair-ali123.itch.io/green-quest)**

## How to Play
1. Click the link above and download `Green Quest.zip` (49 MB).
2. Right-click the ZIP file and select **Extract All**.
3. Open the extracted folder and double-click on **`Green Quest.exe`** to start playing!
